# Podcast Fighter II Turbo

A simple web app to compare two podcasts side by side using their RSS feeds.

## Features
- Compare episode counts
- View average episode duration
- See podcast metadata and images
- Responsive design

## How to use
1. Paste two podcast RSS feed URLs
2. Click "Load Fighter" for each
3. View comparison stats

## Tech Stack
- HTML/CSS/JavaScript (Vanilla)
- Tailwind CSS for styling
- allorigins.win for CORS proxy
